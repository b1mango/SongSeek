# Third-party software

The application includes FFmpeg and FFprobe static binaries. macOS arm64 builds
compile the official [FFmpeg 9.0.2 release](https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz)
from source with a minimal audio-only configuration under **LGPL v2.1 or later**.
GPL, nonfree, networking, video codecs and device support are disabled. Static
[LAME 3.100](https://sourceforge.net/projects/lame/files/lame/3.100/) (LGPL v2 or later)
preserves offline mock MP3 generation; its PCM input is generated by Python.
Both source archives have pinned SHA256 hashes in `scripts/build_desktop.py`.
Build sources, objects and static libraries remain in `.build-cache`, keyed by
versions, hashes and configure flags; no Homebrew libraries are linked or shipped.
The binaries target macOS 12.0, are stripped and ad-hoc signed, and are checked
with `codesign --verify` and `otool -L` (system libraries only).

Windows x64 continues to ship [Gyan's FFmpeg essentials release builds](https://www.gyan.dev/ffmpeg/builds/),
verified against the publisher's SHA256. Those builds enable GPL components and
remain **GPL v3 or later**, not LGPL-only. Build recipes and codec/library versions
are supplied by Gyan. Exact URLs, hashes, configure lines and tool versions are
appended to the copy of this document shipped with every build.

FFmpeg licensing: https://ffmpeg.org/legal.html ; licenses:
https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html and
https://www.gnu.org/licenses/gpl-3.0.html . Retain the matching source, build recipe
and license notices when redistributing these binaries. The macOS LGPL statement
applies to FFmpeg/LAME, not to every dependency of SongSeek.

SongSeek runs these tools as separate command-line processes.

Other included components include Python (PSF), pywebview (BSD-3-Clause),
yt-dlp (Unlicense; bundled dependencies retain their licenses), FastAPI (MIT),
uvicorn (BSD-3-Clause), HTTPX (BSD-3-Clause), Mutagen (GPL-2.0-or-later),
OpenCC Python reimplementation (Apache-2.0), and the React UI (MIT).
PyInstaller's bootloader is GPL with its distribution exception.
